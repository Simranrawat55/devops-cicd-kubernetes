# DevOps CI/CD Kubernetes Project

An end-to-end DevOps project that demonstrates automated testing, Docker containerization, Jenkins CI/CD, and Kubernetes deployment using Minikube.

## 🛠️ Technologies Used

- Python
- Flask
- Pytest
- Docker
- Jenkins
- Kubernetes
- Minikube
- Git & GitHub
